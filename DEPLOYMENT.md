# Deploy to Streamlit Community Cloud

## 1. Создать GitHub-репозиторий

Загрузите содержимое этой папки в отдельный GitHub-репозиторий, например `moex-risk-dashboard`.

Не добавляйте `.venv`, `.env`, `.streamlit/secrets.toml` и содержимое `runtime_cache` — они уже исключены через `.gitignore`.

## 2. Создать приложение в Streamlit Community Cloud

При создании приложения укажите:

- Repository: ваш GitHub-репозиторий;
- Branch: `main`;
- Main file path: `streamlit_app.py`;
- Python: рекомендуется `3.12` (та же версия используется в Dockerfile и CI).

Отдельные секреты для базового запуска не нужны: официальные URL уже заданы в коде и могут быть переопределены только при необходимости.

## 3. Проверка после deployment

Откройте публичный URL и проверьте:

1. `DATA LIVE` / `DATA READY` для выбранного контракта;
2. MR/LK и текущую цену;
3. вкладку «Границы»;
4. `LK1 + 1` и `LK2 + 1` в калькуляторе ГО;
5. календарь специальных режимов.

Если конкретный сайт НКЦ недоступен из инфраструктуры Community Cloud, приложение должно перейти на last-good/fallback, а не обнулить данные.

## 4. Обновления

После изменений достаточно сделать commit/push в GitHub. Community Cloud отслеживает репозиторий и перезапускает приложение после обновления.

## 5. Ограничение локального диска

Файлы, созданные приложением в `runtime_cache`, не следует считать постоянным хранилищем в Community Cloud. При перезапуске инстанса они могут исчезнуть. Для публичной версии это допустимо, поскольку есть официальные live-источники и встроенные подтверждённые fallback-файлы.
