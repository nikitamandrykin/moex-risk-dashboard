# MOEX Risk Dashboard

Аналитическое Streamlit-приложение для практической интерпретации риск-параметров фьючерсов MOEX / НКЦ.


## v1.1.1 Market Monitor Polish

Новый первый экран **«Мониторинг»** показывает один ближайший активный контракт по каждому базисному активу и сортирует инструменты по близости текущей цены к `LOWLIMIT` / `HIGHLIMIT`.

Доступны:

- аналитические статусы `NORMAL / WATCH / CRITICAL` с настраиваемым процентным порогом;
- фильтрация по аналитическим группам: валюта, индексы, акции, товары, металлы;
- отдельные выборки «к верхней границе», «к нижней границе», `Special mode`;
- переход из строки монитора в существующую карточку конкретного контракта;
- дополнительное обогащение параметрами базисного актива НКЦ: запрет/лимит коротких продаж и приём/лимит приёма в обеспечение, когда официальный источник позволяет однозначно сопоставить БА.

Статусы `WATCH / CRITICAL` являются **аналитической классификацией интерфейса**, а не официальными терминами НКЦ. Параметры short/collateral относятся к базисному активу на фондовом или валютном рынке, а не к фьючерсной серии.

В v1.1.1 равноудалённые от `LOW/HIGH` контракты помечаются `↔ CENTER`, а в таблице виден фактически использованный источник цены (`LAST / SETTLE / LAST SETTLE / PREV SETTLE`).

В v1.1.2 параметры short/collateral убраны из агрегированного Risk Radar и показываются только в детальном «Обзоре» выбранного базисного актива, когда НКЦ публикует применимые данные.

## Что показывает приложение

- выбранный базисный актив и конкретную фьючерсную серию;
- текущую цену, `LOTVOLUME`, `MINSTEP`, `STEPPRICE`, стоимость шага и контракта;
- `MR1`, `MR2`, `MR3`, `LK1`, `LK2` и пересчёт LK в количество контрактов;
- `LOWLIMIT`, `HIGHLIMIT` и положение текущей цены внутри коридора;
- дневные и вечерние параметры автоматических раздвижек;
- `OffDaysTradingPriceRangeShift` и аналитическую оценку утренних границ валютных фьючерсов;
- календарь специальных риск-параметров НКЦ;
- ступенчатый аналитический калькулятор ГО.

## Источники

Приложение использует официальные источники MOEX / НКЦ. Для критичных наборов реализована отказоустойчивая цепочка: live-источник → last-good cache → допустимый встроенный официальный snapshot → ручной файл в локальном техническом режиме.

Хороший кеш не перезаписывается пустым или невалидным ответом.

## Публичный и локальный запуск

### Streamlit Community Cloud

Публичный entrypoint: `streamlit_app.py`.

Он автоматически включает public-mode:

- скрывает ручные загрузчики и подробную диагностику;
- не позволяет посетителю очищать общий кэш источников;
- использует общий TTL-кэш между сессиями и отдельный session snapshot для быстрых взаимодействий.

### Локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

На Windows также можно использовать `run_windows.bat`.

## Важные ограничения

- расчёт ГО сверх первого уровня — аналитическая оценка простой позиции в одной серии, а не полный портфельный расчёт НКЦ;
- при оценке утренних валютных границ публичная цена `Pmarket23:50` может заменяться явно подписанным proxy;
- локальное хранилище Streamlit Community Cloud не является постоянным, поэтому runtime cache рассматривается только как временный last-good слой; встроенные официальные fallback-файлы находятся в репозитории.
