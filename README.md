# MOEX Risk Dashboard

Веб-дашборд риск-параметров срочного рынка на **FastAPI + HTML/CSS/JavaScript, без Streamlit в работающем контейнере**.

## Разделы

- **Обзор:** выбор базисного актива и конкретной фьючерсной серии, цена из ISS, стоимость контракта, LOWLIMIT/HIGHLIMIT, MR1–MR3, LK1–LK2, параметры торгов в выходные.
- **Границы:** ценовой коридор, положение цены, параметры автоматических раздвижек в основную и вечернюю сессии, аналитические границы выходного дня, утренние валютные границы.
- **Калькулятор ГО:** ступенчатая оценка по уровням концентрации, быстрые сценарии LK1/LK2 и детализация ГО каждой ступени.
- **Спецрежимы НКЦ:** официальные периоды по базисному активу, дате и времени; различие между «режим не действует», «не указан» и «нет данных».
- **Методика:** справочник параметров, единицы измерения, как применять, формулы и ключевые пояснения.

## Источники и расчёты

Используются опубликованные данные MOEX ISS и НКЦ с проверенными существующими загрузчиками в services/. Данные из разных источников объединяются по базисному активу, поля контрактного уровня — по выбранной серии.

При сбое источника доступны last-good cache и/или встроенный официальный fallback, если он предусмотрен для соответствующего набора. Резервные данные помечаются. Интерфейс опрашивает сервер раз в пять минут; ответ API не гарантирует наличия свежих сделок.

Расчёт ГО — **аналитическая оценка простой позиции одной серии**, а не официальный клиринговый расчёт НКЦ. Расчётные границы выходного/утреннего дня при отсутствии Pmarket23:50 используют явно обозначенный прокси.

## Запуск без Streamlit

    pip install -r requirements-web.txt
    python -m uvicorn web_app:app --host 127.0.0.1 --port 8080

Открыть http://127.0.0.1:8080/.

В Railway используется Dockerfile с requirements-web.txt. Запуск через uvicorn web_app:app на переменном PORT, по умолчанию 8080. Подробнее: DEPLOYMENT.md.

## Тестирование

    pip install httpx
    python tests_fastapi.py

CI проверяет вычисления, ответы API, JavaScript, сборку и запуск Docker-контейнера без Streamlit. Старые app.py / streamlit_app.py сохранены как код предыдущей реализации для возможности отката, но в новый контейнер фреймворк Streamlit не устанавливается.

## Доступность из России

Отказ от Streamlit убирает экран первоначальной загрузки Streamlit, **но не гарантирует доступ без VPN к серверам Railway**. Для этого отдельно проверяется сеть или выбирается иной хостинг.
